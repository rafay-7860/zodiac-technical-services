# Zodiac Cleaning Services

Premium cinematic website for **Zodiac Cleaning Services** — Dubai, UAE.

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion + GSAP
- Lucide React
- React Router

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Editable content

- `src/data/company.ts` — verified business details
- `src/data/services.ts` — proposed service categories (placeholders)
- `src/data/testimonials.ts` — placeholder reviews (`testimonialsEnabled`)
- `public/logo/zodiac-logo.png` — brand logo (used as-is, no added background)
